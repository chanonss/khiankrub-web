# KhianKrub web (built site)

The published web version of KhianKrub, free to use at <https://khiankrub.app>. This repository holds
only the built site, generated by the publish script; do not edit it here. The web app's source
code is private.

KhianKrub is based on [WordCraft](https://github.com/storytold/wordcraft) by the ArtCraft team
(MIT OR Apache-2.0); its copyright and licence notices are in `LICENSE-MIT`, `LICENSE-APACHE`,
`NOTICE` and `ATTRIBUTION.md`. The fonts' licences, the full GPL text and checksums are in
`fonts/`. The desktop app is open source at <https://github.com/chanonss/khiankrub>.

Built from version 0.9.0, commit f35deac7.
